# Weak Points

Known problems in this repository. Tick an item when it is fixed.

- [ ] `nrs` hides the real Homebrew Bundle error. nh prints only stderr, while
      `brew bundle` reports failures on stdout. A failed cleanup shows only
      "Skipping … not installed" warnings. Reproduce with
      `brew bundle cleanup --file=<generated Brewfile>`.
- [ ] Cleanup cannot remove hand-installed apps that carry macOS app protection
      attributes (`com.apple.macl`, `com.apple.provenance`) unless the terminal has
      App Management permission. Activation then fails. Seen when Handy was
      replaced with Hex.
- [ ] Homebrew tap trust is split across two files. Interactive shells set
      `XDG_CONFIG_HOME` and read `~/.config/homebrew/trust.json`. Activation runs
      through sudo without it and reads `~/.homebrew/trust.json`. Trust declared
      in `nix/macos.nix` reaches only the activation file, so interactive `brew`
      can refuse casks from a declared tap (for example `anomalyco/tap`).
- [ ] `nix flake check --no-build ./nix` fails on this Mac with
      `path '/nix/store/rajfap2y…-source.drv' is not valid` while evaluating the
      NixOS configuration. This is local store corruption, not a config error;
      `nix-store --verify --check-contents --repair` should clear it.
- [ ] NixOS generation 107 shipped Vicinae 0.29.2 from a flake input that was
      never committed; the next rebuild from `main` would have dropped it. Build
      only from committed (or at least tracked) state so generations stay
      reproducible.
- [ ] Vicinae settings (`~/.config/vicinae/settings.json`) live outside the
      repo because Vicinae rewrites the file from its GUI. Theme, font, and
      keybinding choices are not versioned.
- [ ] Codex overlay bumps can leave a stale per-platform hash (0.164.0 shipped
      with an outdated `x86_64-unknown-linux-musl` hash, breaking `nrs` on
      NixOS). Overlay updates should prefetch every platform's assets.
- [ ] The official Herdr app and herdr-core (`nix/packages/herdr-app.nix`,
      `nix/packages/herdr-core.nix`) are prebuilt release binaries pinned by
      hand from `releases.herdr.dev/{app,core}/latest.json`; there is no
      upstream flake or update script. The app's built-in self-updater cannot
      write into the Nix store, so updates must be bumped here. The macOS
      packages (Herdr.app, Herdr Core.app in /Applications/Nix Apps) were
      written on NixOS and have not been run on the Mac yet; whether macOS
      keeps Herdr Core.app's local network and microphone permissions from the
      Nix store is untested.
- [x] Herdr app keybindings and settings (`~/.config/herdr-app/keys.json`,
      `settings.json`) live outside the repo: the app rewrites its home
      folder in place, so a repository symlink would be replaced. Fixed:
      `scripts/herdr-app-setup` merges `herdr-app/keys.json` and the theme
      into them.
- [ ] `nvim/lua/config/keymaps.lua` is tab-indented and fails
      `stylua --check --config-path nvim/.stylua.toml` (spaces, width 2).
- [ ] `nvim/lua/config/plugins.lua` declares `lmilojevicc/herdr-splits.nvim`
      twice with identical settings.
- [x] Herdr app Ctrl+h/j/k/l navigation depends on files outside the repo:
      the `nav` mod (`~/.config/herdr-app/mods/nav`), its key bindings, and the
      personal `main-nav` and `terminals-nav` layouts (clones of `main` and
      `terminals` holding the mod in an empty floating block). The clones no
      longer receive Herdr's updates to the shipped layouts. Fixed: the mod is
      linked from `herdr-app/mods/nav`, and `scripts/herdr-app-setup`
      regenerates both layouts from the shipped ones.
- [ ] `scripts/herdr-app-setup` is manual: run it after the first Herdr
      start on a machine and after Herdr updates its shipped layouts. Re-running
      resets theme picks on the `-nav` layouts to the dotfiles theme.
- [ ] The square Herdr look (`mods/<name>-square`, generated by
      `scripts/herdr-app-setup`) rewrites `.rounded*()` calls in copies of
      Herdr's shipped mods by regex. A future mod that rounds corners another
      way (a computed radius, a styled `Button`) stays rounded, and Herdr's own
      popup and dialog frames are not covered.
- [ ] `scripts/agent-threads` reads Claude Code and omp session files by
      their current, undocumented JSONL layout, and OpenCode's
      `session list --format json` fields (`directory`, `time.updated`) are
      guessed: no OpenCode sessions existed to test against. A format change
      silently drops threads from the Herdr `threads` sidebar.
- [x] `scripts/fzf-git.sh` exited every interactive zsh started with
      positional arguments (`zsh -ic 'cmd' zsh args`, how Herdr starts tabs):
      sourced, it took them as its own subcommands. Fixed: `nix/home/shell.nix`
      sources it from an anonymous function.
- [ ] `scripts/agent-usage` reads Claude Code usage from the undocumented
      endpoint behind its `/usage` (`api.anthropic.com/api/oauth/usage`,
      `anthropic-beta: oauth-2025-04-20`) with Claude Code's own OAuth token,
      and Codex usage through omp's sign-in. Either can break on an upstream
      change; the token is never refreshed here, so usage shows a sign-in
      error until Claude Code next runs. The macOS keychain lookup is untested.
- [ ] Threads sidebar pins and settled threads live in the threads mod's
      `localStorage`, per machine and outside the repository.
- [ ] `nix flake check --no-build ./nix` fails while checking
      `nixosConfigurations.nixos` on the Mac with "path
      '/nix/store/rajfap2ywa8n1akz7pasqs8y6ynpr474-source.drv' is not valid",
      on a clean HEAD too; the Darwin configuration evaluates.
- [ ] The quest layout's hud mod (`herdr-app/mods/hud`) runs the game as a
      detached process tracked by pid in `shared("hud.run")` (Stop sends it
      SIGTERM); F5/F8 in that layout no longer reach terminals.
