# Program marks

These are the installed Herdr program SVGs, preserved with their existing
license notices. The portrait tabs tint them natively, without a square chip.

- `codex.svg` omits the outer white app-tile path so the actual scalloped terminal
  mark works as a monochrome mask. Its original central geometry is unchanged.
- `omp.svg` traces the supplied Oh My Pi pixel logo without the wordmark or
  background. It is rasterized for display so the native UI preserves its colors.
- `program.svg` and `agent.svg` are retained for audit reference but excluded from
  the illustrated mapping; Herdr's unknown-program fallbacks remain unchanged.
