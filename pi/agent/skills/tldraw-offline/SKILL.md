# tldraw canvas operator

Read and follow the complete skill installed by tldraw offline at
`$HOME/skills/tldraw-offline/SKILL.md` before operating a canvas.

Use the bundled helper at `$HOME/skills/tldraw-offline/tq`. Keep tldraw offline
open while using the skill. If the shared skill is missing, ask the user to run
**Develop → Install Agent Skills** in tldraw offline.
